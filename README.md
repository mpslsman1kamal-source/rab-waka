# RAB Waka — Frontend (GitHub Pages)
Frontend statis (HTML/CSS/JS vanilla) untuk aplikasi Rancangan Anggaran Belanja Waka. Backend: Google Apps Script (`Kode.gs`, diserahkan terpisah).
1. Isi `GAS_URL` di `js/config.js` dengan URL Web App berakhiran `/exec`.
2. `git init` di folder ini (folder yang berisi `index.html`), commit, push, lalu aktifkan GitHub Pages (branch `main`, folder root).
Panduan lengkap: `PANDUAN-INSTALASI.md`.
